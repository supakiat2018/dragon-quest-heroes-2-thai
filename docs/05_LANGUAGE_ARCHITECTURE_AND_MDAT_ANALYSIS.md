# รายงานการวิเคราะห์สถาปัตยกรรมภาษา วิดีโอ เสียง และระบบฟอนต์ (Language & Asset Architecture)
**เกม:** DRAGON QUEST HEROES™ II (PC / Steam)  
**บันทึกเมื่อ:** 14 ตุลาคม 2026

---

## 1. บทนำและข้อกังวลหลัก (Problem Statement)
ในการพัฒนา Mod ภาษาไทย ได้มีการสำรวจความเป็นไปได้ในการสลับไปใช้ฐานภาษาเอเชีย (เช่น **繁體中文 - Traditional Chinese** หรือ **한국어 - Korean**) เพื่อใช้ประโยชน์จากระบบฟอนต์ CJK ที่มีช่องตัวอักษรมากกว่า 10,000 ช่อง

อย่างไรก็ตาม มีข้อกังวลที่สำคัญคือ:
> *"หากเลือกภาษาจีนตัวเต็ม ภาพในเกม ไอคอน วิดีโอ และเสียงพากย์จะกลายเป็นภาษาจีนหรือไม่?"*

เอกสารฉบับนี้สรุปผลการเจาะระบบและวิเคราะห์ไฟล์จริงในตัวเกมเพื่อตอบคำถามดังกล่าวอย่างละเอียด

---

## 2. โครงสร้างโฟลเดอร์ `mdat` (Movie & Audio Data)

จากการตรวจสอบโฟลเดอร์ `C:\Program Files (x86)\Steam\steamapps\common\DRAGON QUEST HEROES™ II\mdat` พบการจัดเก็บข้อมูลออกเป็น 4 โซนหลัก:

### 2.1 วิดีโอคัตซีน (`mdat\High` และ `mdat\Low`)
* **รูปแบบไฟล์:** ไมโครซอฟท์ **ASF / WMV (Advanced Systems Format)** สังเกตจาก Magic GUID `30 26 B2 75 8E 66 CF 11 A6 D9 00 AA 00 62 CE 6C`
* **การแบ่งความละเอียด:**
  * `High\`: วิดีโอความละเอียดสูง (1080p)
  * `Low\`: วิดีโอความละเอียดปกติ (720p)
* **การแยกไฟล์ตามภาษา (Language Suffixes):**
  วิดีโอที่มีข้อความ/ป้ายกำกับภาษาฝังอยู่ในเนื้อวิดีโอ ถูกแยกไฟล์ชัดเจนตามรหัสภาษา:
  * `m044_EN.dat` (144 MB) $\rightarrow$ วิดีโอฉบับ **ภาษาอังกฤษ**
  * `m044_TWN.dat` (150 MB) $\rightarrow$ วิดีโอฉบับ **ภาษาจีน (Taiwan / Traditional Chinese)**
  * `m044_KOR.dat` (146 MB) $\rightarrow$ วิดีโอฉบับ **ภาษาเกาหลี**
  * `m048_EN.dat` (28 MB) $\rightarrow$ วิดีโอฉบับ **ภาษาอังกฤษ**
  * `m048_TWN.dat` (30 MB) $\rightarrow$ วิดีโอฉบับ **ภาษาจีน (Taiwan)**
  * `m048_DE.dat`, `m048_ES.dat`, `m048_FR.dat`, `m048_IT.dat` $\rightarrow$ ภาษาเยอรมัน, สเปน, ฝรั่งเศส, อิตาลี
  * ส่วนคลิปทั่วไปที่ไม่มีข้อความ (`m000.dat` ถึง `m043.dat`) ใช้ไฟล์ร่วมกัน

### 2.2 ไฟล์เสียงและเพลง BGM (`mdat\sound` vs `mdat\sound_WEST`)
* `mdat\sound\`: ระบบเสียงสำหรับเวอร์ชันเอเชีย (ญี่ปุ่น, จีน, เกาหลี)
* `mdat\sound_WEST\`: ระบบเสียงสำหรับเวอร์ชันตะวันตก (อังกฤษ, ยุโรป)
* **ผลกระทบ:** เมื่อเกมรันโหมดภาษาจีน ตัวเกมจะสลับไปดึงระบบเสียงจาก `mdat\sound` ทันที

## 3. โครงสร้างภาพกราฟิกและไอคอน UI ใน `LINKDATA.BIN`

ไฟล์ภาพ UI ทั้งหมด (ไอคอนปุ่มคอนโทรลเลอร์, แผนที่, ป้ายคำสั่ง, เอฟเฟกต์ภาพ) ถูกแพ็กรวมอยู่ใน `LINKDATA.BIN` ขนาด 12.7 GB:
* ภายในโค้ด `DQH2.exe` มีการแยก Path ทรัพยากรตามภาษา:
  * ฝั่งตะวันตก (อังกฤษ): `../data_WEST/effect/eff_tex_ENG.bin`, `Eff_G1E_ENG.bin`
  * ฝั่งเอเชีย (จีน/เกาหลี): `../data_ASIA/effect/Eff_G1E_KOR.bin` และทรัพยากร CHT
* **ผลกระทบ:** ในโหมดภาษาจีน ป้ายกราฟิกและเอฟเฟกต์บางส่วนจะดึงภาพที่มีข้อความภาษาจีนฝังอยู่มาแสดงผล

## 4. โครงสร้างของระบบฟอนต์ (Font Systems Comparison)

| รายการ | ฝั่งตะวันตก / อังกฤษ (`entry_342`) | ฝั่งเอเชีย / จีน (`entry_341`) |
| :--- | :--- | :--- |
| **ประเภทฟอนต์** | Western Proportional (ตัวหนังสือความกว้างไม่เท่ากัน) | CJK Monospace / Quad System |
| **ขนาดไฟล์** | 1,048,632 ไบต์ (~1 MB) | 33,554,488 ไบต์ (~33.5 MB) |
| **โครงสร้างภายใน** | แผ่น Texture เดี่ยว 1024x1024 (`GT1G0600`) | Bundle รวมภาพย่อย **129 ไฟล์** |
| **จำนวนช่องอักษร** | ~120 ช่อง (แถว 0–10 อังกฤษ, แถว 11–16 รัสเซีย) | **10,000+ ช่อง** (รองรับตัวอักษรจีนทั้งหมด) |
| **การทำงานใน Engine** | โค้ดเรนเดอร์อ่านแบบ 1 ไบต์ (CP1252 / CP1251) | โค้ดเรนเดอร์อ่านแบบ Multi-byte / Big5 / UTF-16 |

> [!CAUTION]
> **ทำไมจึงนำ `entry_341` มาเปลี่ยนชื่อทับ `entry_342` ตรงๆ ไม่ได้?**  
> เพราะ Engine ฝั่งภาษาอังกฤษถูกเขียนโปรแกรมให้อ่าน G1T แบบแผ่นเดี่ยว 1024x1024 หากนำ Bundle 129 ไฟล์ของจีนไปใส่ในช่อง 342 ตัวเกมฝั่งอังกฤษจะ Crash ทันทีที่โหลดเมนู

## 5. เปรียบเทียบ 2 แนวทางในการพัฒนา Mod ภาษาไทย

### แนวทาง A: พัฒนาบนฐานภาษาอังกฤษ (English Core) — **แนะนำ**
* **วิธีการ:** 
  1. คงเกมไว้ในโหมดภาษาอังกฤษ (English) ตามค่าเริ่มต้นของ Steam
  2. วาดฟอนต์ **Pridi-Bold** ทับแถว 0–10 เพื่อให้ฟอนต์อังกฤษเปลี่ยนเป็น Pridi สไตล์เดียวกัน
  3. นำตัวอักษรไทย/คลัสเตอร์สระซ้อน แมปลงในช่องว่างที่เหลือของแผ่น `entry_342` (แถว 11–20 และพื้นที่ว่างด้านขวา/ล่างที่มีอีกหลายร้อยช่อง) แบบ Dynamic PUA
* **ข้อดี:**
  * เสียงพากย์, วิดีโอ, ภาพ UI, ไอคอนปุ่ม เป็นภาษาอังกฤษ 100% ไม่มีภาษาจีนหลุดมาแน่นอน
  * ผู้เล่นดาวน์โหลดม็อดไปติดตั้งแล้วเปิดเกมเล่นได้ทันที ไม่ต้องสลับภาษาใน Steam
* **ข้อพิจารณา:** ต้องจัดการช่องว่างอักษรไทยให้พอดีกับคำที่ใช้ในเกม

---

### แนวทาง B: สลับฐานเป็นภาษาจีน แต่คัดลอกไฟล์อังกฤษทับ (Fake English on CJK)
* **วิธีการ:** 
  1. ให้เกมรันในโหมด `繁體中文 (Traditional Chinese)` ใน Steam เพื่อเปิดระบบ CJK 10,000 ช่อง
  2. ก๊อปปี้ไฟล์วิดีโอ `m044_EN.dat` $\rightarrow$ `m044_TWN.dat`, `m048_EN.dat` $\rightarrow$ `m048_TWN.dat`
  3. คัดลอกภาพ UI ฝั่งอังกฤษใน `LINKDATA.BIN` ไปทับฝั่งจีน
  4. นำข้อความภาษาไทยใส่ลงใน `entry_210.bin` (Text จีน)
* **ข้อดี:** ปลดล็อกช่องตัวอักษรภาษาไทยไม่อั้น ใส่ได้ทุกคำในพจนานุกรม
* **ข้อพิจารณา:**
  * ต้องตามแก้ไฟล์วิดีโอและภาพหลายจุดเพื่อให้ไม่มีภาษาจีนหลุดรอด
  * ผู้เล่นทุกคนต้องตั้งค่าภาษาใน Steam เป็นภาษาจีนก่อนเข้าเกม
