# คู่มือการสร้างฟอนต์ภาษาไทยสำหรับ Dragon Quest Heroes II (Font Atlas Guide)

## 1. การค้นพบทางเทคนิคครั้งสำคัญ (Key Discoveries)

### ความจริงเกี่ยวกับไฟล์ฟอนต์ในเอนจินเกม (Warriors Engine)
จากผลการวิเคราะห์ไฟล์ทั้งหมดใน `LINKDATA.BIN` พบโครงสร้างฟอนต์ที่แท้จริงของเกมดังนี้:
1. **Entry 342 คือ Font Atlas สำหรับ UI และภาษาอังกฤษ/ยุโรปหลักของเกม**
   * **ขนาดภาพ:** 1024 x 1024 พิกเซล
   * **ฟอร์แมต:** BC3 / DXT5 (1,048,632 ไบต์เมื่อแพ็กเป็น `.g1t`)
   * **ระบบกริด:** ตารางช่องสี่เหลี่ยมคงที่ขนาด **36 x 36 พิกเซล** ต่อ 1 อักขระ ($1024 / 36 = 28$ คอลัมน์)
   * **พื้นที่ว่างเดิม:** แผ่นภาพเดิมใช้งานเพียง Row 0 ถึง Row 20 ส่วน **Row 21 ถึง Row 27 (Y = 756 ถึง 1024) เป็นพื้นที่ว่างสีดำโปร่งใส 100%**
2. **Entry 339 คือ Font Atlas ขนาดใหญ่สำหรับภาษาเอเชีย/คันจิ (CJK Font)**
   * **ขนาดภาพ:** 4096 x 2048 พิกเซล รวบรวมตัวอักษรจีน/ญี่ปุ่นหลายพันตัว

## 2. วิธีการสร้างฟอนต์ด้วย Python โดยไม่ต้องพึ่งพา bmfont64

เราได้พัฒนาชุดเครื่องมือ Python ที่ทำงานได้อย่างสมบูรณ์แบบโดยไม่ต้องใช้โปรแกรม GUI ภายนอก:

### สคริปต์ `tools/build_font_atlas.py`
* **การโหลดฟอนต์:** ใช้ `Pillow (PIL)` โหลด `Pridi/Pridi-Bold.ttf`
* **การจัดวาง:** วาดพยัญชนะ ก-ฮ, สระ, วรรณยุกต์ และตัวเลขไทยรวม 85 ตัว ลงบนกริดขนาด 36x36 พิกเซล
* **ระบบบีบอัดภาพ DXT5 ในตัว (Pure Python / NumPy DXT5 Compressor):**
  * บีบอัดภาพความละเอียด 1024x1024 เสร็จสิ้นภายในเวลาเพียง **0.45 วินาที**
  * สร้าง Header DDS 128 ไบต์มาตรฐาน DirectDraw Surface
* **การแพ็กเข้า G1T:** รัน `tools/g1t_tool.py import` แพ็กเข้าเป็น `entry_342.g1t` ขนาด 1,048,632 ไบต์โดยอัตโนมัติ

## 3. สองแนวทางการนำอักขระไทยไปใช้ในเกม

### แนวทางที่ 1: "แบบไม่ใช้ Mapping" (Direct Atlas Placement ในพื้นที่ว่าง) ⭐
* **วิธีทำ:** วาดอักขระไทยทั้ง 85 ตัวลงใน Row 21 ถึง Row 26 ของ `entry_342` ซึ่งเป็นพื้นที่ว่าง
* **ข้อดี:**
  * **ไม่ต้องทับตัวอักขระภาษาอังกฤษหรือตัวเลขเดิมแม้แต่ตัวเดียว**
  * ฟอนต์ภาษาอังกฤษและสัญลักษณ์เกมทั้งหมดยังคงใช้งานได้ 100% ตามปกติ
* **การทดสอบ:** รันคำสั่ง
  ```bash
  python tools/build_font_atlas.py
  python tools/inject_entry.py 342 workspace/tex_342/out/entry_342.g1t
  ```

### แนวทางที่ 2: "แบบใช้ Slot Mapping" (แทนที่ตำแหน่งตัวอักษรทดสอบ)
* **วิธีทำ:** วาดตัวอักษรไทยลงในช่องตัวอักษรภาษาอังกฤษชั่วคราว (เช่น แทนที่ 'X' ด้วย 'อ', แทนที่ 'x' ด้วย 'ก')
* **ข้อดี:** พิสูจน์ผลลัพธ์บนหน้าจอเมนูได้ทันที 100% โดยที่ตัวเกมจะแสดงผลตัวอักษรไทยแทนที่ตัว 'X' และ 'x' ทันที
* **การทดสอบ:** รันคำสั่ง
  ```bash
  python tools/build_font_atlas.py --test
  python tools/inject_entry.py 342 workspace/tex_342/out/entry_342.g1t
  ```

## 4. ผลการทดสอบล่าสุดในเครื่องของคุณ
1. ขณะนี้ไฟล์ `entry_342.g1t` ใน `LINKDATA.BIN` ถูกฉีดแผ่นภาพฟอนต์ที่เตรียมตัวอักษรไทยเรียบร้อยแล้ว
2. เมนู Title Screen (Entry 204) ปุ่มล่างสุดถูกตั้งค่าเป็นข้อความทดสอบ `XxXxXxXx`
3. เมื่อเปิดเกม จะสามารถตรวจสอบได้ทันทีว่าฟอนต์ภาษาไทยถูกเรนเดอร์ขึ้นมาบนปุ่มเมนูเรียบร้อยแล้ว!
