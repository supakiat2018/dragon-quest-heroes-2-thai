# คู่มือฟอนต์และแนวทางการทำภาษาไทย (Font & Thai Localization)

## 1. ลักษณะของฟอนต์ในเกม Dragon Quest Heroes II
* เกมค่าย Koei Tecmo ยุคนี้ใช้ฟอนต์ 2 รูปแบบผสมกัน:
  1. **Texture/Bitmap Font (ไฟล์ `.g1t`):** ตารางรูปภาพตัวอักษร (Glyph Atlas) ที่สร้างมาคู่กับตารางรหัสตัวอักษร มักใช้ใน UI, หัวข้อเมนู, และปุ่มกด
  2. **Vector Font / FreeType (OTF/TTF):** ในบางจุดของระบบข้อความยาวๆ

## 2. อุปสรรคสำคัญของการแปลภาษาไทย
1. **การแสดงผลตัวอักษร (Glyphs):**
   * เกมภาษาอังกฤษดั้งเดิมจะมีเฉพาะชุดตัวอักษร ASCII และตัวอักษรยุโรปบางตัว (เช่น é, ü)
   * เมื่อเราพิมพ์ภาษาไทย ตัวเกมจะไม่รู้จัก Glyph และอาจแสดงผลเป็นช่องว่าง หรือเครื่องหมาย `?`
   * **วิธีแก้:** ต้องแก้ไขไฟล์ภาพ Texture ฟอนต์ `.g1t` โดยวาดตัวอักษรภาษาไทยลงไปแทนที่ หรือขยายตารางตัวอักษร
2. **ปัญหาสระลอยและวรรณยุกต์ซ้อน (Thai Diacritics):**
   * ภาษาไทยมีสระบน (ิ, ี, ึ, ื) และวรรณยุกต์ (่, ้,๊, ๋) อยู่บนพยัญชนะ
   * เกมที่ไม่มีระบบ Thai Text Shaping Engine ในตัว มักจะวาดสระและวรรณยุกต์ซ้อนทับกัน หรือกระโดดลอยสูงผิดปกติ
   * **วิธีแก้เบื้องต้น:**
     - ปรับตำแหน่ง Glyph ในตารางตัวอักษร
     - ใช้ฟอนต์แบบตัดหาง หรือรวมสระกับวรรณยุกต์เป็น Glyph เดียวกันสำหรับคู่คำที่ใช้บ่อย
