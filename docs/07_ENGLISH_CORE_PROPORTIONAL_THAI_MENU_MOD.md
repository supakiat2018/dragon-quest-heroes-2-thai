# รายงานการติดตั้ง Mod เมนูภาษาไทยบนฐานภาษาอังกฤษ (English Core Proportional Mod)
**เกม:** DRAGON QUEST HEROES™ II (PC / Steam)  
**บันทึกเมื่อ:** 14 ตุลาคม 2026  
**สถานะ:** ติดตั้งเข้า LINKDATA.BIN สำเร็จ 100% พร้อมทดสอบในเกม!

---

## 1. บทนำและวัตถุประสงค์
หลังจากทดสอบระบบ CJK ในภาษาจีนตัวเต็มและพบว่าระบบตัวหนังสือถูกเว้นช่องไฟคงที่ 36px (Monospace) แบบตัวพิมพ์ดีด ผู้ใช้ได้ตัดสินใจเปลี่ยนมาใช้ **แนวทางที่ 1 (แผน A: English Core บน `entry_342`)** เพื่อให้ตัวหนังสือภาษาไทยเรียงตัว **ชิดกันสวยงามตามธรรมชาติ (Proportional)** และรักษาเสียงพากย์, วิดีโอคัตซีน และป้าย UI ทั้งหมดให้อยู่ในเวอร์ชันภาษาอังกฤษแท้ 100%

## 2. วิธีการแก้ปัญหาความไม่สวยงามจากรอบก่อน (Technical Innovations)

1. **ขจัดปัญหาการยืดหดภาพ (No Stretching):**
   * รอบที่แล้วมีโค้ด `resize()` ยืดตัวอักษรให้เต็มช่อง ทำให้ตัวหนังสืออ้วนแบน
   * รอบนี้ **รักษาขนาดและสัดส่วนจริงของ `Pridi-Bold.ttf` 100%** (Font Size 32, Baseline Y=32 ตรงกับตัวอักษรเดิมของเกม)
2. **การจับคู่ช่องความกว้างอย่างประณีต (Precise Width Matching):**
   * วัดขนาดจริงของตัวอักษรไทยทุกตัว และนำไปวางในช่องอักษรรัสเซีย (Cyrillic Row 11–15) ที่ Engine มีค่า Advance Width ตรงกัน
3. **ระบบจัดช่องไฟธรรมชาติ (Natural Typography Kerning):**
   * **สระหน้า (`เ`):** วางชิดขวาของช่อง เพื่อให้ชิดพยัญชนะตัวถัดไป
   * **สระหลัง (`า`):** วางชิดซ้ายของช่อง เพื่อให้ชิดพยัญชนะตัวหน้า
   * **พยัญชนะเดี่ยวและคลัสเตอร์:** วางกึ่งกลางความกว้างของช่อง
