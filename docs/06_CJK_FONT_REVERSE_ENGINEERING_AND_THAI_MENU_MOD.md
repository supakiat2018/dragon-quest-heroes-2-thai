## 2. การค้นพบทางวิศวกรรมย้อนรอย (Reverse Engineering Discoveries)

### 2.1 โครงสร้าง Font Atlas ภาษาจีน (`entry_340.g1t`)
* **ความละเอียดภาพ:** 4096 x 8192 พิกเซล
* **ฟอร์แมตพื้นผิว:** BC3 / DXT5 (`GT1G0600`) ขนาดไฟล์แตกแล้ว 33,554,488 ไบต์
* **ขนาดช่องอักขระ (Cell Size):** **36 x 36 พิกเซล** ต่อช่อง พอดีกับตาราง CJK สี่เหลี่ยมจัตุรัส
* **จำนวนคอลัมน์ต่อแถว:** 4096 // 36 = **113 คอลัมน์ต่อแถว** (พิกเซลที่ 4068-4095 เป็นขอบ Padding 28px)
* **การจัดเรียงรหัสอักขระ (Encoding Layout):**
  ตัวอักษรใน Atlas ถูกจัดเรียงเป็นอาร์เรย์ 1 มิติแบบต่อเนื่อง (Linear 1D Array) ตามมาตรฐาน **Big5 (CP950)**:
  * **ดัชนี 0 ถึง 407 (แถว 0 Col 0 ถึง แถว 3 Col 68):** เครื่องหมาย สัญลักษณ์ และอักษรกรีก (`0xA140` ถึง `0xA3BF`) รวม 408 ตัว
  * **ดัชนี 408 เป็นต้นไป (แถว 3 Col 69 เป็นต้นไป):** ตัวอักษรจีนมาตรฐาน เริ่มต้นที่ `0xA440` (`一`) โดยแต่ละ Lead Byte มี 157 ตัวอักษร
* **สูตรคำนวณตำแหน่งพิกเซล (X, Y) จากรหัส Big5:**
  ```python
  def big5_to_coord(b1, b2):
      if b1 == 0xA1:
          idx = (b2 - 0x40) if b2 <= 0x7E else (63 + b2 - 0xA1)
      elif b1 == 0xA2:
          idx = 157 + ((b2 - 0x40) if b2 <= 0x7E else (63 + b2 - 0xA1))
      elif b1 == 0xA3:
          idx = 314 + ((b2 - 0x40) if b2 <= 0x7E else (63 + b2 - 0xA1))
      else:
          base = 408 + (b1 - 0xA4) * 157
          offset = (b2 - 0x40) if b2 <= 0x7E else (63 + b2 - 0xA1)
          idx = base + offset
          
      row = idx // 113
      col = idx % 113
      return col * 36, row * 36
  ```

### 2.2 โครงสร้าง Text Engine ภาษาจีน (`entry_210.bin`)
* **ขนาดไฟล์เดิม:** 70,720 ไบต์
* **การเข้ารหัสข้อความ:** **UTF-8** พร้อม Pointer Table 32-bit (Little-Endian)
* **สูตร Pointer:** `Pointer Value = File Offset - 0x20`
* **ตำแหน่ง Pointer ของเมนูหลักทั้ง 7 รายการ:**
  1. `เริ่มการเดินทาง` (แทนที่ `開始冒險`): Pointer Offset `4032` (0xFC0)
  2. `สร้างบันทึก` (แทนที่ `建立冒險之書`): Pointer Offset `4036` (0xFC4)
  3. `ลบบันทึก` (แทนที่ `刪除冒險之書`): Pointer Offset `4040` (0xFC8)
  4. `ตั้งค่ากราฟิก` (แทนที่ `圖像設定`): Pointer Offset `6800` (0x1A90)
  5. `ตั้งค่าคีย์บอร์ด` (แทนที่ `鍵盤設定`): Pointer Offset `6804` (0x1A94)
  6. `ตั้งค่าเมาส์` (แทนที่ `滑鼠設定`): Pointer Offset `7092` (0x1BB4)
  7. `ออกจากเกม` (แทนที่ `結束遊戲`): Pointer Offset `6808` (0x1A98)

## 3. สถาปัตยกรรม PUA และความกระจ่างเรื่องความอ้วน/ผอมของตัวหนังสือ

### ข้อสงสัยของผู้ใช้:
> *"ถ้าทำ pua มันพิมพ์ไทยทีละสองตัวในช่องเดียว แบบนี้ตัวอ้วนผอมไม่เท่ากันสิ 555... แล้วก็ทำทีละสองตัว เช่น กล กข กง ได้หรือไม่?"*

### คำตอบและหลักการออกแบบที่ถูกต้อง:
1. **ในแนวนอน (Horizontal):** **ห้ามรวมสองพยัญชนะเข้าด้วยกันเด็ดขาด!** (เช่น `กล`, `กข`, `กง`)  
   เพราะถ้าเอาพยัญชนะ 2 ตัวมาบีบในช่อง 36x36 จะทำให้ตัวอักษรผอมลีบ อ่านยากมาก และสูญเสียสัดส่วนฟอนต์ที่สวยงาม
2. **สิ่งที่ต้องรวมเป็น 1 ช่อง (Cluster):** คือ **การซ้อนกันในแนวตั้ง (Vertical Stacking)** เท่านั้น!  
   เช่น:
   * `ริ่` (ร + สระอิ + ไม้เอก) $\rightarrow$ 1 ช่อง (กว้าง 36x36 สวยงาม คมชัด ไม่ต้องมีสระลอย)
   * `ดิ` (ด + สระอิ) $\rightarrow$ 1 ช่อง
   * `บั` (บ + ไม้หันอากาศ) $\rightarrow$ 1 ช่อง
   * `ตั้` (ต + ไม้หันอากาศ + ไม้โท) $\rightarrow$ 1 ช่อง
3. **พยัญชนะและสระเดี่ยว:** ให้ 1 ตัวต่อ 1 ช่องตามธรรมชาติ (`ก`, `า`, `เ`, `น`, `ง`, `ม`, `อ`)  
   ทำให้ทุกตัวอักษรมีความหนาและสัดส่วนที่สม่ำเสมอเท่ากันทั้งหน้าจอ
